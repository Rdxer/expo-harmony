# @expo-harmony/expo-status-bar

为 HarmonyOS 上的 React Native 应用提供 `expo-status-bar` 的兼容入口。

## 安装

```bash
npm install @expo-harmony/expo-status-bar expo-status-bar@55.0.6
```
